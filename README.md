# Formation Canalisateur — Application complète

Application de formation au **Titre Professionnel Canalisateur** (niveau 3 – RNCP).

## Contenu

### 8 modules de formation
1. Le métier de canalisateur
2. Sécurité & Habilitations (AIPR, CACES, SST, EPI)
3. Lecture de plans & Implantation
4. Préparation de chantier & Terrassement
5. Pose de canalisations d’assainissement
6. Regards, branchements & ouvrages
7. Réseaux d’adduction d’eau potable
8. Essais, mise en service & Qualité

### Quiz de validation
- 15 questions
- Score minimum pour l’attestation : **12/15**

### Attestation de suivi
- Débloquée uniquement quand les 8 modules sont validés **et** le quiz est réussi
- Possibilité d’inscrire son nom et d’imprimer / enregistrer en PDF

## Comment utiliser

1. Décompressez le fichier ZIP
2. Ouvrez `index.html` dans Chrome (ordinateur ou téléphone)
3. Sur Android : Menu Chrome → « Ajouter à l’écran d’accueil »

## Structure

```
canalisateur-app/
```
